Ushbu sahifa “Web dasturlashga kirish” fanining birinchi amaliy ishi doirasida HTML5 va CSS3 asosida tayyorlandi.

Loyihaning maqsadi

Saytning maqsadi avtomobil haqidagi asosiy ma'lumotlarni sodda va tushunarli shaklda taqdim etishdir.

Foydalanuvchi e'lonni ko'rib, avtomobilning narxi, yili, yoqilg'i turi va joylashuvi bilan tanishishi mumkin.

Ushbu bosqichda loyiha faqat HTML va tashqi CSS faylidan tashkil topadi; server yoki ma'lumotlar bazasi ulanmagan.

Keyingi amaliy ishlarda saytga jadval, forma, moslashuvchan maket va JavaScript funksiyalari qo'shilishi mumkin.

Avtomobil xaridida narx bilan birga texnik holat va hujjatlarni tekshirish ham muhim.

Sayt hozircha o'quv maqsadida yaratilgan va undagi e'lonlar haqiqiy savdo taklifi hisoblanmaydi.

“Maqsad — kerakli ma'lumotni sodda, aniq va qulay ko'rsatish.”

HTML sahifa tuzilishini belgilaydi, CSS esa uning ko'rinishini boshqaradi.
